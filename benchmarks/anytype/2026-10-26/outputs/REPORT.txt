Any-sync synthetic sync benchmark — issue 46
https://github.com/ledgerloops/ledgerloops/issues/46

Measured: native any-sync LocalOnly object trees over authenticated loopback
yamux/DRPC, with native any-store persistence. Both peers run in one process.
This measures the underlying protocol and adapter, not the Anytype application.

All 3 models completed 3 warmups + 10 measured transfers: 39 fresh receivers.
Full fixture and update hashes passed every initial and final reopen check.
Independent Python verification confirmed all values, not just record counts.
Original fixture: 132 records / 415,448 bytes / expected manifest SHA-256.

Allocated bytes equal apparent bytes for these medians; both are in the raw
results. Native history, indexes and surviving metadata/WAL files count.
Native stats: 4 collections, 5 indexes. External service storage is zero for
this direct-peer topology only; official network service storage is unmeasured.

Modeling: record_trees uses 132 trees, one record operation each.
collection_blocks uses 2 trees with 21/111 record operations; these are adapter
operations, not Anytype blocks. opaque_collections uses 2 whole-array payloads.
JSON serialization preserves every source field, nested value, null and order.
Native Anytype properties, application indexes, discovery, concurrent editing
and the full server topology are outside the measured scope. Space header,
ACL/settings and tree IDs are bootstrapped before timing. Synthetic keys are
retained in memory across DB reopen. ACLs use official LocalOnly full author
validation, without consensus acceptor signatures. Both peer identities are
authenticated; CID, signature, encryption and ACL rejection checks pass.

Flush acknowledgement follows the native SDK: FULL/EXTRA SQLite commits
already synchronize; otherwise its FSYNC API temporarily commits under FULL.
Reopen checks do not prove power-loss durability or macOS F_FULLFSYNC behavior.
Wire counters include protobuf envelopes and native yamux/DRPC transport
framing; they exclude TCP/IP/Ethernet headers, retransmissions and handshake.
Default RPC compression is off; no compressed-wire estimate is substituted.

Anytype application and official service-stack variants remain unmeasured.
The Docker daemon socket is absent. Existing services were not restarted.
These native results must not be labeled as full Anytype performance.
