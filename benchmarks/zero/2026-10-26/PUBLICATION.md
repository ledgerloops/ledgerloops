# Publication copy

These measurements were collected on 2026-10-26 for ledgerloops/ledgerloops#44 and published at the user’s request on 2026-10-27. Numerical measurements, fixture content, dependency versions and correctness evidence are unchanged.

The personal home-directory prefix in recorded paths is represented as `$HOME`; the rest of each recorded storage path is preserved. The shell runtime path and Python shared-lock path use the current home directory rather than a personal username. Synthetic benchmark passwords and JWT keys are public test constants, as documented in README.md.

The shared coordination directory in `with_lock.py` must exist and be configured for the runner before running benchmarks.
